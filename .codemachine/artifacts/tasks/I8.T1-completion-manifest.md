## Pre-Deployment Checklist

Before deploying to any environment, ensure:

1. ✅ Kubernetes cluster is provisioned (EKS for AWS)
2. ⚠️ metrics-server is installed (required for HPA)
3. ⚠️ ALB Ingress Controller or Nginx Ingress is installed
4. ⚠️ External Secrets Operator is installed (or manual secret creation)
5. ⚠️ Update `<IMAGE_PLACEHOLDER>` in overlay kustomization files
6. ⚠️ Replace `<DOMAIN_PLACEHOLDER>` in ConfigMap patches
7. ⚠️ Replace `<ACM_CERTIFICATE_ARN_PLACEHOLDER>` in Ingress
8. ⚠️ Configure production secrets (database, JWT, OAuth, Stripe, AWS)
9. ⚠️ DNS records point to Ingress load balancer
10. ⚠️ SSL certificates are valid
