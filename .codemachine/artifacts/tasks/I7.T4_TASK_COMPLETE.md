## Key Implementation Features

### 1. Protocol Support
- **OIDC:** Full support with authorization code flow, PKCE (codeVerifier), ID token validation
- **SAML2:** Full support with SAML response parsing, assertion validation, certificate verification

### 2. Security Features
- **Domain Verification:** User email domain must match organization domain (lines 479-485)
- **SSO Configuration Validation:** Organization must have SSO configured (lines 449-453)
- **Error Response Security:** 401 for unknown domain (prevents information disclosure)

### 3. Error Handling
- **400 Bad Request:** Invalid parameters (missing code, protocol, email, redirectUri, codeVerifier)
- **401 Unauthorized:** Authentication failed, domain mismatch, org not found, SSO not configured
- **500 Internal Server Error:** Unexpected exceptions

### 4. Design Patterns
- **Fire-and-forget Audit Logging:** Async CDI event, doesn't block response
- **Graceful Duplicate Handling:** Recovers from IllegalStateException for existing org members
- **Reactive Error Recovery:** Uses `.onFailure().recoverWithItem()` for expected errors
- **Protocol-Specific Parameters:** Conditional SsoAuthParams construction

```
1. Request Validation (lines 397-432)
   ├─ Validate code, protocol, email
   ├─ For OIDC: validate redirectUri, codeVerifier
   └─ Extract IP address, User-Agent

2. Organization Lookup (lines 436-443)
   ├─ Extract email domain
   └─ Find organization by domain (fail if not found)

3. SSO Config Validation (lines 449-453)
   └─ Verify org.ssoConfig exists

4. SSO Authentication (lines 456-473)
   ├─ Build SsoAuthParams (protocol-specific)
   └─ Call SsoAdapter.authenticate()

5. Domain Verification (lines 479-485)
   └─ Verify user domain matches org domain

6. JIT User Provisioning (lines 489-495)
   └─ UserService.findOrCreateUser()

7. Organization Assignment (lines 502-516)
   ├─ OrganizationService.addMember(MEMBER role)
   └─ Recover from duplicate member (returning users)

8. JWT Token Generation (lines 522-526)
   └─ JwtTokenService.generateTokens()

9. Audit Logging (lines 529-534)
   └─ AuditLogService.logSsoLogin() [fire-and-forget]
```
